# RL — прохождение лабиринта

## Файлы

- `Qlearning.py` — Q-learning агент
- `DQN.py` — DQN агент
- `dqn_model.zip` — сохранённые веса DQN

## Лабиринт

Задан как numpy-массив 19×20. `-1` — стена, `0` — проход, `2` — старт, `1` — цель. Агент стартует в `[1, 1]`, цель в `[17, 18]`. Четыре действия: вверх, вниз, влево, вправо.

## Q-learning

Классическая реализация без нейросетей. Q-таблица — трёхмерный массив (строки × столбцы × 4 действия).

Параметры: `alpha=0.1`, `gamma=0.95`, `epsilon=1.0` с затуханием `0.995` до минимума `0.05`. Обучение — 1000 эпизодов по 500 шагов.

Награды: `-1` за удар о стену, `-0.1` за шаг, `+10` за достижение цели.

После обучения скрипт сохраняет Q-таблицу в `Q_table.npy`, рисует тепловую карту посещений, показывает визуализацию движения агента и тестирует политику 100 раз, выводя процент успешных прохождений.

## DQN

Вместо таблицы — нейронная сеть MlpPolicy. Наблюдение: полная карта лабиринта, где позиция агента отмечена значением `3`. Реализовано через кастомную среду `MazeEnv` на базе `gymnasium.Env`.

Параметры: `learning_rate=0.001`, `buffer_size=5000`, `batch_size=1024`, `gamma=0.95`, `total_timesteps=20000`.

Награды немного другие: `-5` за стену, `+100` за цель, и небольшой бонус за приближение к финишу на каждом шаге.

После обучения скрипт прогоняет агента по лабиринту и рисует его путь. Модель сохраняется в `dqn_model.zip`.

Загрузить сохранённую модель:

```python
from stable_baselines3 import DQN
model = DQN.load("dqn_model")
```
